# Dennis Catana — Media Kit

Public media kit / creator portfolio site for brand partnerships.

**Repo:** https://github.com/deece27/denniscatana-media-kit  
**Handles:** [@denniscatana](https://www.instagram.com/denniscatana/) · YouTube · TikTok  
**Domains (ready later):** denniscatana.com · denniscatana.ca

## Local preview

Open `index.html` in a browser, or:

```bash
npx serve .
```

## Deploy (Vercel)

1. Import this repo in [Vercel](https://vercel.com)
2. Framework: Other · Root: `.` · Output: static
3. Point Squarespace DNS for `denniscatana.com` / `.ca` when ready

Chat with Cursor → changes committed here → Vercel redeploys.
